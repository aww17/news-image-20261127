# The World in One Page - Friday 27 November 2026

A one-image newspaper front page summing up the world news of Friday 27 November 2026:
a masthead, the date, a standfirst and seven stories across regions and beats, on white
with dark navy text and one red accent. Entry for
[make.fun/news-image-20261127](https://make.fun/bounty/news-image-20261127).

`entry.png` is a 1024 by 1024 infographic rendered from HTML with headless Chromium at
exactly that size. `main.py` (Python 3.13, standard library only) copies `entry.png`, which
sits beside it, into the directory named by MAKEFUN_OUTPUT_DIR, or into `/output` when that
variable is unset, creating the output directory if it does not exist.
